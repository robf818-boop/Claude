# AutoFlipper

**Personal Event-Driven Options Trading Dashboard**

A private, password-protected web application for monitoring and simulating options trading strategies.

## Features

- **Real-time Dashboard**: Monitor signals, positions, and risk metrics
- **Event-Driven Architecture**: Four-module system (Sentinel, Oracle, Executor, Warden)
- **Technical Analysis**: EMA, RSI, ATR, MACD with confluence scoring
- **Options Support**: Greeks, IV, delta-based contract selection
- **Risk Management**: Circuit breakers, drawdown limits, position monitoring
- **Paper Trading**: Simulated execution for testing strategies

## Quick Start

```bash
npm install
npm run dev
```

## Deployment

Deploy to Vercel:
1. Connect GitHub repo
2. Deploy from `main` branch
3. Access from any device

## Private Use

This app is password-protected for personal use only.
