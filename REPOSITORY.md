## What is DefendIQ?

DefendIQ is an interactive web application designed to help baseball coaches teach and players learn proper defensive positioning for various game situations.

### Key Features
- **Visual Learning**: Interactive baseball field with player positions
- **Preloaded Situations**: 20+ common defensive scenarios
- **AI Generator**: Create custom situations using natural language
- **Rules Handbook**: Searchable database of baseball rules
- **Age-Appropriate**: Content for T-Ball through 18U
- **Multi-Platform**: Web, iOS (via Capacitor)

### Use Cases
- Pre-practice preparation
- On-field training reference
- At-home study for players
- Game preparation
- Post-game review
